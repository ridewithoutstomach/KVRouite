# Voice Remover (core/stimme) - since 7.0. python-audio-separator is the
# separation core of Ultimate Vocal Remover as a library; it pulls in torch,
# onnxruntime, scipy, numpy and librosa (about 750 MB installed).
#
# The library declares a dependency on "diffq" (Windows: "diffq-fixed") that
# must not come in: diffq-fixed is licensed CC BY-NC 4.0 and cannot be
# shipped, and on Python 3.14 it has no wheel and its source package does not
# even build. The two lines below install KVRouite's own stand-ins under
# those names FIRST (tools/diffq_platzhalter), so pip sees the library's
# demand as met and never asks PyPI for the originals. Run pip from the
# project directory - the paths are relative to it.
#
# Linux: torch from PyPI ships CUDA (2.5 GB). Install the CPU build FIRST:
#     pip install torch==2.14.0 torchvision==0.29.0 --index-url https://download.pytorch.org/whl/cpu
#
# Building the executable needs Python 3.12.1 or newer: 3.12.0 has a bug
# (CPython issue 110543) that breaks scipy inside a PyInstaller build. The
# packer checks the Python version and that "diffq-fixed" is the stand-in.
./tools/diffq_platzhalter/diffq_fixed
./tools/diffq_platzhalter/diffq
